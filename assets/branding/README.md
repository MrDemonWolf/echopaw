# EchoPaw brand direction

**Working identity.** EchoPaw uses an original speech bubble with a three-toed paw and a short waveform. The app icon and demonstration character each use their own artwork. The creator’s personal stream mascot stays private and outside this identity.

| Token | sRGB |
| --- | --- |
| Navy 900 | `#0A1633` |
| Navy 800 | `#0D2A56` |
| Navy 700 | `#0D4D8C` |
| Blue 600 | `#1178B8` |
| Blue 500 | `#1795D2` |
| Blue 400 | `#3AAEE3` |

Use Montserrat for branded headings and Roboto for branded body text. Preserve macOS system typography on native controls and system menus. For custom view text, size and weight must remain comfortable with macOS accessibility settings. Use rounded shapes, off-white light surfaces where needed, and dark navy copy on bright blue. Give controls text labels and a distinct focus ring.
