title: Advanced Setup
description: Add only the connections and controls your stream needs.
---

Begin with a working [offline preview](/start/five-minute-setup/). Each listed step is a separate setup task you can resume after a failed test or skip when you do not need the feature.

| Step | Why it matters | Test |
| --- | --- | --- |
| [Twitch broadcaster](/connect/twitch-broadcaster/) and [bot](/connect/twitch-bot/) | Receive channel events and optionally use a separate chat identity. | Verify both displayed accounts. Simulate an event before enabling live replies. |
| [OpenAI](/connect/openai/) | Generate and check short replies. | Run a private sample and confirm the chosen model and cap. |
| [ElevenLabs](/connect/elevenlabs/) | Generate the voice your character speaks. | Confirm commercial rights if applicable and preview one line in headphones. |
| [Character states](/character/expressions/) and [outfits](/character/props-outfits/) | Add optional visuals. | Switch states and confirm the image stays aligned. |
| [Microphone](/stream/microphone/) and [keyword](/stream/keyword/) | Add optional reactions and hands-free interactions. | Confirm each mode and its listening indicator independently. |
| [OBS](/stream/obs/) and [audio output](/stream/audio/) | Show the character and route its voice. | Make a local recording. |
| [Stream Deck](/stream/stream-deck/) | Add optional hardware controls. | Confirm stop, disconnect and status behavior. |

Before enabling live output, rehearse with a simulated mention and mute during playback. Review [PackGuard](/reference/packguard/) and set a [provider budget](/reference/cost/).
