This is the planned first run on Apple Silicon with macOS 15 or later. For something you can try now, open the [browser interface preview](/start/interface-preview/).

<SetupChecklist />

1. Open **Quick Start** to run a local preview. It skips provider connections and microphone permissions. Practice off-stream because a configured OBS scene can still capture the visible mascot or test sound.
2. Choose the sample or drop in your [two images](/character/images/). The preview should show both poses without shifting the character. If a file is missing or mismatched, select the folder again after fixing it.
3. Run **Test output** at a low volume. If it is silent, check your Mac's current output and the app's volume, then retry.
4. Open the dashboard and locate **Mute speech** and **Emergency stop** before any live setup.

For a stream, continue with [OBS](/stream/obs/) or choose individual steps in [Advanced Setup](/start/advanced-setup/).
