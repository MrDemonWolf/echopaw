---
title: Install on macOS
description: Check compatibility and install the signed DMG when available.
---

EchoPaw targets Apple Silicon and macOS 15 or later. The offline preview is available to build from source. A public native installer is pending.

When a release is available:

1. Open [GitHub Releases](https://github.com/MrDemonWolf/echopaw/releases) and choose the stable DMG.
2. Open the disk image, drag EchoPaw to Applications and eject the disk image.
3. Start EchoPaw from Applications and choose [Quick Start](/start/five-minute-setup/).
4. If macOS cannot verify the developer, confirm the release source and report the issue. Leave Gatekeeper enabled.

Read [releases and updates](/develop/releases/) for the stable and nightly policy.

## Uninstall and remove data

Disconnect and revoke provider connections before removing the app from Applications. If you want to remove local packs and settings as well, export art you own first and use the app's planned data removal controls. Follow the release-specific privacy guide for the precise local data paths and Keychain entries.
