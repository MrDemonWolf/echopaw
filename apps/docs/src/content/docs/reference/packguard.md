---
title: How PackGuard works
---

PackGuard checks eligible input and complete replies before any voice or chat delivery. It fails closed if a required check fails or times out.

- **SFW**, **PG-13** and **Twitch-safe Mature** tune the channel's style. PG-13 is the starting preset.
- Mandatory restrictions still apply in every preset. Redeems, Bits, prompts and manual overrides cannot skip them.
- Custom rules can ignore, block, request a checked rewrite, use a canned response, play a silent animation, hold for review, or notify the streamer.
- Logs show minimal reason and status information. Use simulated inputs to test rules before going live.

When speech is blocked, rely on a silent reaction and inspect the status locally. Test **Emergency stop** before enabling live output.
