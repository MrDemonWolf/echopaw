---
title: Frequently asked questions
---

### Do I need subscriptions or API keys?

You can use the planned offline preview without any accounts. Cloud dialogue and voices will require the relevant provider accounts and permission to use them.

### Can I use it on Intel, Windows or Linux?

The planned native app targets Apple Silicon with macOS 15 or later.

### Does EchoPaw automatically capture my microphone?

Both mic features start off and require independent opt-in. Use the dashboard or menu bar to stop listening. See [microphone activity](/stream/microphone/).

### Can it read every chat message aloud?

Balanced chooses selected triggers subject to cooldowns, queue capacity and PackGuard. Twitch-derived cloud responses depend on third-party processing approval.

### Will EchoPaw ship with the creator's personal character?

Bring your own art or try the separate sample planned for Quick Start.

### Do I need BlackHole or a Stream Deck?

Both are optional. Start with [OBS per-app capture](/stream/obs/) and the app's keyboard controls.
