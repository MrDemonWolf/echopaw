---
title: Set up ElevenLabs
---

Use ElevenLabs Free only for private noncommercial testing in EchoPaw. A monetized stream, VOD or clip requires commercial rights that cover the selected voice and intended use.

1. Create an [ElevenLabs account](https://elevenlabs.io/) and review the [pricing and commercial license](https://elevenlabs.io/pricing).
2. Preview an existing voice you have permission to use or design an original voice in [Voice Design](https://elevenlabs.io/docs/eleven-creative/voices/voice-design/). Check voice-specific rights and consent before using a voice based on a real person.
3. Create a dedicated, limited API key with the supported voice permissions. Enter it in EchoPaw's installed app when the integration is available.
4. Select the voice, set a [budget](/reference/cost/) and test a short approved line off-stream. If access fails, check the key permissions, available credits and model availability before retrying.

Update the usage declaration before switching from private testing to a monetized session. The app cannot certify your rights.
