---
title: Stream Deck integration
---

Stream Deck is planned as an optional add-on. Use the app and its keyboard shortcuts without installing a plugin.

Once a compatible plugin is released:

1. Install it from a verified EchoPaw release and enable the local connection in the native app.
2. Confirm **Connected** before assigning an action.
3. Add **Mute speech**, **Pause AI**, and **Emergency stop** first. Later actions can include push-to-talk, mode, expression, outfit and manual reaction.
4. Test **Emergency stop**, then quit EchoPaw. The plugin should show the disconnected state and remain inactive until it reconnects.

If the connection fails, check that local controls are enabled and that both apps use compatible versions, then restart them. Keep credentials out of screenshots and support requests.
