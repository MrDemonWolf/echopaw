---
title: Releases and updates
---

EchoPaw is in planning. The [GitHub Releases page](https://github.com/MrDemonWolf/echopaw/releases) is the planned source for signed, notarized DMGs when builds are ready.

- **Stable** is the default channel for production streaming.
- **Nightly** is opt-in when available. Use it outside a live session while testing.
- The planned in-app updater uses Sparkle to validate signed update artifacts. Review release notes and leave time to rehearse after updating.
- If verification fails, keep the installed build and check official release notes. Report the exact error without bypassing verification.

Before the first release the project must test fresh install, signed update, channel separation, failed payload rejection and the recovery steps.
