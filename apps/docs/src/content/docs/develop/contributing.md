---
title: Contributing
---

Start with the [contribution guide](https://github.com/MrDemonWolf/echopaw/blob/main/CONTRIBUTING.md) and the [project planning index](https://github.com/MrDemonWolf/echopaw/blob/main/docs/README.md).

1. Pick a focused research, documentation or approved validation change.
2. For a new technical claim, cite the official source and record the evidence or outstanding test.
3. Run the [docs checks](/develop/installation/) and document what you verified.
4. Keep API keys, user data, creator-only artwork and personal voice assets out of the repository.

See the [code of conduct](https://github.com/MrDemonWolf/echopaw/blob/main/CODE_OF_CONDUCT.md) and [security reporting guidance](https://github.com/MrDemonWolf/echopaw/blob/main/SECURITY.md).
