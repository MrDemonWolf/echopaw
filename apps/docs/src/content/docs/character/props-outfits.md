---
title: Props and outfits
---

Props and outfits are optional extras. Keep the base idle and talking images complete.

When the layer editor is available, add a transparent prop, set its anchor and use the on-screen numeric controls or drag to position, scale and rotate it. Preview both base poses and test at your actual OBS size. Outfits that replace the base should include an aligned pair.

If an optional asset is missing, select the base outfit or hide that prop before troubleshooting. Export only art you own or have permission to redistribute.
