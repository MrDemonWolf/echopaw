# MVP and roadmap

Updated November 18, 2026. Build the daily-use path in short slices. Every new output path must pass PackGuard and stop tests before a test broadcast.

| Phase | Scope | Exit evidence |
| --- | --- | --- |
| Planning | Research, decisions, design system, browser prototype, docs, risk and validation plans. | Static site builds and local links work. Open gates have acceptance criteria. |
| Native spike | Signed arm64 launch, two-state PNG import and playback-driven sprite, one local test clip, isolated OBS capture and device-loss test. | A macOS 15 OBS recording shows correct pose and exactly one copy of each audio source. Stop and output loss are measured. |
| Offline MVP | Safe Quick Start, original sample or imported pack, System Default and explicit route, replayable fixtures, mute, latched emergency stop, accessible keyboard controls. | Five-minute first-run study, accessibility review, native and OBS soak. |
| Twitch MVP | Broadcaster and bot connections, connection recovery, local eligible reactions, event dedup and Balanced pacing. Begin with mentions, selected keywords and Channel Points where authorized. Add Bits, custom Power-ups, raids and subscriptions as their event handling is validated. | Two identities and revoked/reconnected flows walked through. One logical event produces at most one scheduled action. |
| Cloud MVP, gated | OpenAI Luna and ElevenLabs v4 Turbo when available and approved. Full input/output/final checks, controlled output, approved scripted and AI speech, budgets. | Written provider-policy disposition, commercial rights, safety suite, live stop and cost-accounting results. |
| Release validation | First signed/notarized DMG, Sparkle feed design, stable notes, owner-approved capture and voice test, privacy review. | Clean installer and genuine update test across signed builds. |
| Later | Mic activity, local keyword recognition, optional deck, visual layer editing, additional expressions/outfits, opt-in viewer memory and explicit cloud STT. | Each feature gets its own rights, reliability and accessibility checks. |

Keep Quiet, Balanced, Chatty and Chaos in the scheduling specification. Expose high-frequency presets only after bounded behavior and overload tests. Defer OBS automation, visual scripting, full avatar rigs, cross-platform support and App Store distribution.
