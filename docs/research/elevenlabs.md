# ElevenLabs voice integration

**Status** First-party documentation checked November 18, 2026. No account, paid tier, voice ID, commercial entitlement, latency or API call was tested.

Use the user's ElevenLabs key and one eligible voice. Start with Eleven v4 Turbo (`eleven_v4_turbo`) and a single HTTP stream of text that PackGuard has fully approved. This keeps dialogue, voice preview, and paid usage easy to track. The provider lists about 100 ms median inference latency for the model. Measure network, moderation, generation, first byte, decoding and audible output separately before reporting latency. [Model catalog](https://elevenlabs.io/docs/overview/models#eleven-v4-turbo) · [Latency guidance](https://elevenlabs.io/docs/eleven-api/guides/how-to/best-practices/latency-optimization)

## First-time setup

1. Start with EchoPaw's offline sample. It tests the character and playback route without provider calls. Use an OBS local recording for route verification and keep the stream offline.
2. Create or sign in to an [ElevenLabs account](https://elevenlabs.io/). Choose private noncommercial testing or commercially licensed voice use. Check the current terms and plan before generating live-use audio.
3. In ElevenLabs, create a named restricted API key with Text to Speech and voice/model lookup access where the provider permits it. Use a credit limit if available. Paste once into EchoPaw's secure field, then keep it in Keychain. EchoPaw never exports the key or asks for the provider password. Grant subscription access only if the user wants an account readout and the integration needs it. [Key management](https://elevenlabs.io/docs/overview/administration/workspaces/api-keys) · [API authentication](https://elevenlabs.io/docs/api-reference/authentication)
4. Pick a voice the account can use. Search existing voices via the provider or use ElevenLabs Voice Design for an original description, listen to the three candidates, save one and return to EchoPaw. Enter or select the saved voice ID. The provider charges for the preview text once per Voice Design generation, despite producing three candidates. Voice Design stays on the provider site in the MVP. [Voice Design](https://elevenlabs.io/docs/eleven-creative/voices/voice-design/) · [List voices](https://elevenlabs.io/docs/api-reference/voices/search)
5. Verify model support and run one explicit short EchoPaw preview. Show that the call can spend quota. Play it on the selected route, show output meter and provide Stop. Leave live voice disabled until the streamer deliberately confirms rights, completes the route test and arms the live session.

Instant Voice Cloning requires permission and clones may be account-restricted. Professional Voice Cloning lets each person verify and clone their own voice and share an eligible clone privately where supported. A voice ID does not convey permission, and publicly listed voices can have separate restrictions or be removed. EchoPaw imports no samples and performs no cloning in the MVP. [Cloning overview](https://elevenlabs.io/docs/eleven-creative/voices/voice-cloning/) · [Professional Voice Cloning and sharing](https://elevenlabs.io/docs/eleven-creative/voices/voice-cloning/professional-voice-cloning)

## Commercial-use decisions

- **Free:** ElevenLabs Free lacks a commercial license. EchoPaw restricts Free or unverified rights to private noncommercial tests. ElevenLabs requires attribution when Free-plan content is shared noncommercially, subject to its terms. Paying later does not retroactively license generations made without commercial rights. [Publishing rules](https://elevenlabs.io/docs/help-center/legal/can-i-publish-the-content-i-generate-on-the-platform)
- **Monetized stream:** Require an eligible paid commercial license or written rights from ElevenLabs for the plan, voice, use and model. Product eligibility can change. Beta Services cannot be used commercially or in production under the published beta rules. A metered PAYG balance can coexist with Free, so a positive balance alone proves no rights. The API may report subscription data, but that cannot establish voice-level or contract rights. [Billing](https://elevenlabs.io/docs/overview/administration/billing) · [PAYG](https://elevenlabs.io/docs/overview/administration/pay-as-you-go) · [Subscription API](https://elevenlabs.io/docs/api-reference/user/subscription/get/) · [Terms of Service](https://elevenlabs.io/terms-of-use)
- **Live interlock:** Default rights to unconfirmed at setup and after key/workspace/voice/model changes. Known Free blocks commercial live audio absent a documented provider exception. Missing billing permission or an unknown tier stays unconfirmed unless the user records an eligible right based on the current terms. An account eligibility readout is advisory, and streamer confirmation belongs to each configured voice/model. Recheck on renewal/downgrade where available. Offer silent preview and independently available approved text routes if rights are unresolved.

The pricing page checked November 18 shows Free with 10,000 monthly credits, 30,000 monthly credits on Starter and Starter's commercial-license listing. Billing docs list three Voice Design slots on Free. Check checkout for current regional prices, offers and account-specific model access. [Plan pricing](https://elevenlabs.io/pricing) · [Billing and credits](https://elevenlabs.io/docs/overview/administration/billing)

## API and playback contract

- Use a fixed HTTPS provider base and `xi-api-key` header. Fetch paginated voices and supported models with the user key. Use the model capability `can_do_text_to_speech`, where returned, plus the known compatible model and parameter table. A successful catalog read does not prove streaming, voice compatibility or plan inclusion.
- Call `POST /v1/text-to-speech/{voice_id}/stream` using PackGuard's exact approved text and the chosen model. Use HTTP audio streaming with complete approved text. Start the compatibility test with the documented default `mp3_44100_128`, then measure whether a compatible smaller PCM format offers simpler buffering or lower latency. The documentation restricts 44.1 kHz PCM to Pro and high-bitrate 192 kbps MP3 to Creator or higher. Skip deprecated latency parameters and arbitrary control tags. If v4 Turbo is unavailable, show reason and allow explicit user selection of another tested compatible model with confirmed rights and budget.
- Read status and content type before decoding, buffer a bounded amount, use a serial playback queue and release buffers after stop. Render talking on actual playback, not text submission. Use the selected Core Audio route and stop on a required output loss. Cancel the HTTP stream and drop buffers immediately on mute or Emergency Stop. Cancellation or decoder failure after submission can still incur charges. [Stream speech](https://elevenlabs.io/docs/api-reference/text-to-speech/stream) · [List models](https://elevenlabs.io/docs/api-reference/models/list)
- Show invalid key/scope, unavailable or removed voice/model, quota, concurrency, timeout and output-change status distinctly. On 401/403, recheck access or replace the key. For 429, distinguish throttled/concurrency from quota when available, let stale reactions expire and respect provider retry guidance. For ambiguous failures or playback already started, skip automatic retries and preserve the cost reservation. Never replay partial audio automatically. [Errors](https://elevenlabs.io/docs/eleven-api/resources/errors)
- TTS gets the final approved utterance only, with no microphone recording, provider-irrelevant identity or chat history. Cloud preview uses the same treatment. Disclose provider usage/history and privacy settings. ElevenLabs documents an Enterprise zero-retention option using `enable_logging=false` where available. Ordinary EchoPaw use cannot promise provider zero retention. Do not send Twitch-derived text without the [Twitch data gate](../architecture/twitch.md#twitch-data-release-gate). [Zero retention mode](https://elevenlabs.io/docs/eleven-api/resources/zero-retention-mode) · [ElevenLabs privacy policy](https://elevenlabs.io/privacy-policy)

## Cost and usage estimates

The API pricing page lists **$0.04 per 1,000 input characters** for metered v4 Turbo. This is a reference rate, separate from taxes, fixed monthly fees, available plan credits, previews, other workspace use, and how a subscription converts characters into credits. At 150 average characters per accepted utterance, 200 utterances are 30,000 characters and about **$1.20 metered equivalent**. At 1,000 utterances the estimate is **$6.00**. [ElevenAPI pricing](https://elevenlabs.io/pricing/api?v=1019) · [Billing](https://elevenlabs.io/docs/overview/administration/billing)

Maintain a local ledger of attempted requests and conservatively counted characters. Provider debits and returned model/plan rates are authoritative when available. Show provider usage comparison instead of requesting broader read scopes just for cost estimates. The ElevenLabs dashboard shows credit use and account metrics. Keep provider fees outside the local hard cap on EchoPaw requests, and never turn on PAYG Auto Top Up on the user's behalf. [ElevenLabs usage](https://elevenlabs.io/docs/overview/administration/account) · [Reaction limits](../architecture/reaction-scheduler.md#budget-proposals)
