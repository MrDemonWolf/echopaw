# Feasibility and risk

Research checked November 18, 2026. **Documented** means a supported API or provider path is described. **Unverified** means EchoPaw has no runtime evidence. **Release gate** limits the named feature.

| Risk | Evidence now | Proof or fallback |
| --- | --- | --- |
| Third-party Twitch data sharing | **Release gate.** Twitch Developer Services Agreement VI.C restricts sharing Twitch Data and derivatives with third parties without prior written permission. VI.F covers deletion. [Twitch agreement](https://legal.twitch.com/en/legal/developer-agreement/). | Confirm permission for each intended transfer, including moderation, generated dialogue inputs and derived speech, and implement deletion. Gate those paths. Use synthetic examples and local visual events in the interim. |
| Desktop OpenAI user-owned keys | **Release gate.** OpenAI supports project keys and recommends server-side key handling for apps. Direct desktop BYOK and Keychain do not establish provider approval. [OpenAI authentication](https://developers.openai.com/api/reference/overview/#authentication). | Confirm the proposed public desktop flow with OpenAI. Check actual key scopes and model access. Preserve the no-required-backend product constraint unless explicitly revisited. |
| OBS window alpha | **Unverified.** AppKit can present a transparent window and OBS documents window capture. | Signed arm64 spike. Record a checkerboard scene across macOS 15/current, Retina/non-Retina where available, visibility and wake. Validate explicit chroma key if necessary. [Native architecture](../architecture/native.md). |
| Duplicated or misrouted mascot voice | **Documented, unverified here.** OBS 30+ supports per-app capture. Explicit device route behavior depends on hardware, OS and capture path. | Record game, mic and mascot separately. Test device removal, Bluetooth, BlackHole, sample rate changes and monitor paths. Stop on loss of a selected route. [Audio](../architecture/audio-routing.md). |
| Twitch connection, duplicate events or shared chat | **Documented, integration unverified.** Public Device Code Grant and user-token EventSub are documented. | Two real identities in an owner-approved test channel. Check grants, refresh, revocation, scope loss, reconnect, dedup and delivery ambiguity. [Twitch design](../architecture/twitch.md). |
| Unsafe output or overrun after stop | **Release gate.** Moderation supports selected categories and does not establish policy coverage or zero false negatives. | Deterministic rules and fixtures, safety regression cases, no partial dispatch and proof that cancellation invalidates pending work. Fail closed. [PackGuard](../architecture/packguard.md). |
| Surprise cost or unlicensed use | **Release gate.** Model price and commercial tiers documented. Account entitlements and invoicing remain unverified. | Confirm rights and plan before live speech. Use pre-call quota reservations, usage accounting, hard dispatch caps and cancellation tests. [ElevenLabs](elevenlabs.md), [budgets](../product/budgets.md). |
| Privacy and recording expectations | **Unverified.** Permission and local recognition APIs are documented, with OS/locale dependencies. | Test denial, revoke, input swap, no transmissions for activity, on-device recognition, PTT and audio feedback. Keep mic features disabled by default. [Microphone](../architecture/microphone.md). |
| Pack import and malformed images | **Design specified.** Untrusted containers and oversized images can affect stability or local files. | Validate types, dimensions and staged copy, exercise invalid pack fixtures, resource limits, replacement and rollback. [Character packs](../architecture/character-packs.md). |
| Public brand collision | **Release gate** for final name. Exact-name uses were located. | Owner reviews clearance and identifiers before release. [Naming](naming.md). |
| Updates and optional deck control | **Documented, unverified.** WolfWave offers patterns for signing and plugin structure. | Test notarized releases, updater rejection, channel separation and real deck stop behavior. [Distribution](../architecture/distribution.md), [Stream Deck](../architecture/stream-deck.md). |

The first prototype should settle OBS capture and audio on a signed minimum-OS build. Provider policy and name clearance can proceed in parallel without making cloud calls with live viewer data.
